# Караокеры vs рокеры — техпроект вечера 27.11.2026

Сайт-конспект по технической части вечера: что за оборудование, что куда втыкается,
что делать, если что-то сломалось, и чем это показывать залу.

**Живая версия:** https://papahsa101-cell.github.io/opera-tech-27-nov/

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | обзор: вводные, три главных риска, ссылки на разделы |
| `tekhproekt.html` | технический проект: оборудование, канальная карта FLOW 8, электрика, YouTube/VPN, риски, роли |
| `ranbook.html` | ранбук: тайминг по часам, чек-листы, планы Б |

| `sxema-interaktiv.html` | интерактивная схема: переключение вариантов, каналы, расчёт питания |
| `pult.html` | пульт ведущего: слайды на проектор, заметки, таймер |
| `kartochki.html` | карточки для печати (A4, шесть стопок) |

## Как править

1. **Тексты проекта и ранбука** живут в markdown: `../PROEKT-27-11.md` и `../RUNBOOK.md`
   в папке проекта. Правка там → пересборка → страницы обновились:

   ```bash
   python gen_site.py
   ```

2. **Схема** (статическая) правится в `../sxema-signal.html` — `gen_site.py` забирает оттуда SVG.
3. **Интерактивная схема**, **пульт** и **карточки** — самостоятельные файлы, их можно править напрямую.
4. `assets/style.css` — общий вид: цвета, отступы, таблицы, печать.
