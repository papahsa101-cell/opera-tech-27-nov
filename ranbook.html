Клавиши пульта

  • ← / → — предыдущий / следующий блок
  • N — заметки ведущего (только на ноутбуке, на экран не идут)
  • T — старт / пауза таймера блока (после нуля считает минус красным)
  • B — затемнение экрана (антракт, смена реквизита)
  • P — проекторный режим: убирает всё, кроме крупного текста
  • F — полный экран · R — сброс таймера

Два экрана — лучший вариант: пульт на ноутбуке ведущего, P-режим на проекторе во втором окне.

Роли

  • Ведущий — держит счёт времени, объявляет правила одной фразой, не объясняет механику дважды.
  • Оператор — проектор, минусовки (оба файла открыты заранее), запись джема, подборка кадров, монтаж.
  • Гитаристы — две песни + одна запасная на блок 1, отдельный короткий список для караоке-крокодила.
  • Suno-оператор — один аккаунт, один запуск победившей заявки, никакой генерации на сцене.

Чек-лист за 3 дня

  • Списки песен под каждую стопку: жанр и десятилетие — только там, где есть готовая песня
  • Минусовки: обе на блок 1 + запасная, по 2–3 хита на каждого артиста из крокодила
  • Карточки распечатаны и разрезаны, стопки физически разделены
  • Определён финальный общий припев и его текст на экран
  • Проверено: клип из кадров делает живой человек, а не «как-нибудь успеется»

Чек-лист за час

  • Пульт открыт, P-режим проверен на проекторе, шрифт читается с последнего ряда
  • Минусовки проиграны от начала до конца — не «файл открывается»
  • Телефон ведущего в тишине, но с таймером
  • Группа для сбора кадров создана, ссылка у зала
  • Локальная копия карточек и минусовок — на ноутбуке, не только в облаке

Честные границы

  • Скрытая ссылка — не защита. Отдельная ссылка для ведущего прячет блок от случайного гостя, но файлы сайта доступны по прямым адресам. Для сюрприза этого достаточно; для настоящей приватности — локальная копия или страница с авторизацией.
  • Согласие на показ в зале ≠ согласие на публикацию. Кадры с вечера не выкладываем в интернет без отдельного «да».
  • Клип делает человек. Я могу собрать монтаж, но только после теста доступа к группе и реального прогона; резервный сборщик назначается заранее.
